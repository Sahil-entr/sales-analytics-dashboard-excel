# Sales Analytics Dashboard

## Overview

This project presents an interactive Sales Analytics Dashboard developed in Microsoft Excel to analyze sales performance, customer behavior, profitability, and regional trends. The dashboard transforms raw sales data into meaningful visualizations, enabling stakeholders to monitor key performance indicators and support data-driven decision-making.

---

## Dataset

The project uses a sales dataset containing **9,993 records** and **11 columns**, including information such as:

- Order Date
- Customer Name
- Product
- Category
- Sales
- Profit
- Quantity
- Discount
- State
- Region
- Customer Segment

---

## Project Objectives

- Analyze overall sales performance.
- Identify top-performing customers and product categories.
- Track monthly sales and profit trends.
- Compare sales across different states and regions.
- Build an interactive dashboard for business reporting and analysis.

The dashboard provides interactive visualizations for:

## How to Run

1. Clone or download this repository.
2. Open `salesdataforexceldashboard.xlsx` using Microsoft Excel (Excel 2019, Excel 2021, or Microsoft 365).
3. Navigate to the **Dashboard** worksheet.
4. Use the slicers to interactively filter and explore the data.
